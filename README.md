# ふたりで一隻（デモ版）

2人で1隻の宇宙船を動かす協力シューティング。ひとりは船を動かす**パイロット**、もうひとりはコンボを入れて撃つ**ガンナー**。

**遊ぶ:** https://raybbb101.github.io/futari-isseki/
（スマホの Chrome で開いて「アプリをインストール」すると全画面で遊べます。ソロはオフラインでも遊べます）

見た目の試作（スプライトスタッキング）: https://raybbb101.github.io/futari-isseki/lab/

## 端末と役

| | パイロット | ガンナー |
|---|---|---|
| 端末 | GameSir X5 Lite（コントローラー）＋スマホ横画面 | GameSir Pocket Taco（ポケットタコ）＋スマホ縦画面 |
| 画面 | 戦場ぜんぶを上から見る | 砲台の窓から見た景色（画面の上だけ使う。見える範囲は「せってい」で調整、初期値 64%） |
| やること | 移動・回避・シールド・加速 | コンボを入れて撃つ（十字の4方向＋ABXY、斜めなし） |

## 遊び方

- **マルチ**：ひとりが「ルームをつくる」で4文字のコードを出し、もうひとりが「コードで参加」で入力。役をえらんで、ホストが START で出発。
- **ソロ（お試し）**：
  - パイロットのお試し … ガンナーは自動でずっと撃ち続ける
  - ガンナーのお試し … 船は自動でよけ続ける（トレーニング）
  - ポーズ（START）から役を入れかえられる

## そうさ

| | パイロット | ガンナー |
|---|---|---|
| 十字／スティック | 移動 | コンボ入力 |
| A | 回避ロール（一瞬むてき） | コンボ入力 |
| B | シールド（エネルギーを使う） | コンボ入力 |
| X | ガンナーに合図 | コンボ入力 |
| Y | – | コンボ入力 |
| L1 ／ R1 | –／加速 | ねらう敵をかえる |
| RT（R2） | 加速 | チャージ砲（エネルギー60） |
| SELECT | – | パイロットに合図 |
| START | ポーズ | ポーズ |

キーボード（テスト用）: 矢印=十字 X=A Z=B S=X A=Y Q=L1 R=R1 E=R2 Enter=START Shift=SELECT

## ステージ（デモ）

約2分。小惑星とドローン → 機雷とレイダー → 砲台・コンテナ・結晶 → 宇宙クラゲ → ボス「戦艦ドレッド」（砲台4つ → 艦橋）→ ワープゲートに飛びこんでクリア。

- 砲台は船の前（扇形の中）しかねらえない。パイロットが敵を扇形に入れる。
- コンボをまちがえると少しのあいだ「ジャム」。
- コンテナ＝エネルギー回復、結晶＝パワーアップ（12秒コンボが短くなる）。

## しくみ

- 絵はすべてプログラムで作った**スプライトスタッキング**（輪切りの絵を重ねて回す）。光の向きは画面に固定で、回すと明るい面と暗い面が入れかわる。
- 通信は PeerJS（WebRTC）でスマホどうしを直接つなぐ。送るのは入力と位置だけで、1時間あたり約5MB。
- ビルド不要の HTML + JavaScript。

| ファイル | 内容 |
|---|---|
| `js/models.js` | ボクセルのモデル（船・敵・障害物・惑星） |
| `js/models2.js` | 2倍の細かさ＋法線とAOを焼きこむ |
| `js/stack.js` | 光を当てて描く・角度ごとのキャッシュ |
| `js/sim.js` | ルール（ホストの世界、ゲストの複製、操作、自動操縦） |
| `js/views.js` | パイロット画面・ガンナー画面 |
| `js/net.js` | ルームコードと通信 |
| `js/main.js` | メニュー・ロビー・ゲームの流れ |
