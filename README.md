# ふたりで一隻（デモ版 v2）

2人で1隻の宇宙船に乗って、広い宇宙を旅するゲーム。ひとりは船を動かす**パイロット**、もうひとりは船じゅうの砲台をあやつる**ガンナー**。住める惑星をさがして、惑星をスキャンし、図鑑を集めていく。

**遊ぶ:** https://raybbb101.github.io/futari-isseki/
（スマホの Chrome で開いて「アプリをインストール」すると全画面で遊べます。ソロはオフラインでも遊べます）

見た目の試作（スプライトスタッキング 36種）: https://raybbb101.github.io/futari-isseki/lab/

## 世界

- **3D の宇宙**。上下・左右・前後、どこへでも飛べる。ある方向にずっと飛ぶと、ぐるっと一周して元の場所にもどる。
- 真ん中に**太陽**。**惑星が8つ**、太陽のまわりを回りながら（公転）、それぞれの速さで自転している（月はアクア・ノヴァのまわりを回る）。太陽の光で昼と夜の側がある。
- 惑星は近づくと大きく、はなれると小さくなる。引力があって、近づきすぎると引きこまれて墜落する（太陽も）。RT の全力加速なら脱出できる。遠くには、いくら近づいても大きくならない別の星の惑星も見える。
- 敵や生きものは宇宙を動き回っている（砲台や機雷は動かない）。
- **ホーム・ステーション**：スタート地点。近くにいると船が修理される。
- 小惑星帯、宇宙ゴミ、機雷原、砲台。宇宙の生きもの（クラゲ、ウナギ、甲虫、エイ、クジラ、ほうしダマ）、海賊の戦闘機や砲艦、商人の船、迷子の探査機。**敵対・中立・友好**がいる。
- ふだんは**探索モード**。敵がおそってくると**戦闘モード**になる。逃げきるのも、迎え撃つのも自由。

## そうさ

**パイロット（コントローラー）**

| ボタン | 動き |
|---|---|
| 左スティック | 前後・左右に移動 |
| 右スティック | 向きを変える |
| RB ／ LB | 上へ ／ 下へ |
| RT | 全力加速（引力から脱出できる） |
| LT | ブレーキ |
| A | 回避ロール |
| B | シールド |
| X | 惑星スキャン（近くで）／中止 |
| Y | 視点を切りかえ |
| SELECT | 図鑑 |
| START | ポーズ |
| L3 | チルトの中心を合わせる |

**ガンナー（ポケットタコ）**

| ボタン | 動き |
|---|---|
| A 長押し | 機関砲（照準の近くに敵がいれば少し追いかける） |
| B ためて離す | チャージビーム（照準の真ん中に近いほど強い） |
| 十字 → X | スキル（下の表） |
| ↑→↓← → Y | 必殺技ノヴァ・バースト（ゲージ満タン） |
| Y 長押し | 照準の中の相手をスキャン → 図鑑に記録 |
| L1 ／ R1 | 左 ／ 右を向く |
| L2 ／ R2 | 上 ／ 下を向く |
| L1＋R1 | 近くの敵をロックオン（もう一度で解除。敵がいなければ船の前を向く） |
| SELECT | 図鑑 |
| START | ポーズ |

ガンナーはいつでも自分で見る向きを変えられます（船じゅうの砲台から360度）。砲台の向きは宇宙に固定されていて、パイロットが曲がってもガンナーの見ている方向は変わりません。

**ロックオン**：弾を当てた敵（または L1+R1 でいちばん近い敵）にロックオンすると、その敵が動いても自動で追いかけます。はなれすぎる・たおす・自分で向きを変えると外れます。パイロットの画面にも「ガンナーがロック中」と出ます。スキルのコンボは図鑑の「スキル」ページで確認します（画面に一覧が出るのはトレーニングのときだけ）。

| スキル | コンボ | 得意な相手 |
|---|---|---|
| 拡散弾 | ← → X | 小さい敵の群れ |
| 貫通ランス | → → X | かたい敵（ガンシップ・甲虫・戦艦） |
| 冷凍弾 | ↓ ↓ X | 速い敵（インターセプター・ウナギ） |
| EMPパルス | ↑ ↑ X | 機械（ドローン・砲台）。敵の弾も消す |
| 連鎖雷 | ↑ ↓ ↑ X | まとまった敵 |
| ノヴァ・バースト | ↑ → ↓ ← Y | 前にいる敵ぜんぶ（ゲージ満タン） |

どの敵にどのスキルが効くかは、スキャンすると図鑑に書かれます。

キーボード（テスト用）: 矢印=十字/左スティック　IJKL=右スティック　X=A Z=B S=X A=Y Q=L1 R=R1 W=L2 E=R2 Enter=START Shift=SELECT

## 遊び方

- **マルチ**：ひとりが「ルームをつくる」で4文字のコード → もうひとりが「コードで参加」→ 役をえらんでホストが START。
- **ソロ（お試し）**：
  - パイロットのお試し … ガンナーは自動で撃ち続ける
  - ガンナーのお試し（トレーニング）… 船が自動で惑星をめぐってスキャンし、敵がよく来る
- **惑星スキャン**：惑星に近づくと「X：スキャン」が出る。30〜55秒かかり、そのあいだ船は動けない。ときどき敵がおそってくるので、ガンナーが守る。終わると図鑑に、名前・種類・年齢・気温・大気・住みやすさなどがのる。
- 図鑑はスマホに保存され、ゲームオーバーになっても消えない。
- 旅は10秒ごとと、タイトルにもどるときに保存される。ソロやルームをつくるときに「はじめから／つづきから」をえらべる（マルチではホストの保存を使う）。ゲームオーバーになると旅の保存は消える。

## しくみ

- 船や生きものはプログラムで作った**スプライトスタッキング**。見る角度に合わせて絵をえらび、距離で大きさを変えて 3D に見せている。遠くのものはなめらかに縮小。船と戦闘機は3倍の細かさ。
- 惑星は表面の地図を作って、球として1ピクセルずつ描いている（太陽の光、自転、雲、溶岩の光、大気、環）。ふだんはドット絵（スプライトスタック風：ドットの格子・段階的な陰影・輪切りの層・ふちどり）、せっていで「なめらか」にもできる。
- 通信は PeerJS（WebRTC）でスマホどうしを直接つなぐ。送るのは操作と近くの動くものの位置だけで、1時間あたり約10MB。
- ビルド不要の HTML + JavaScript。
